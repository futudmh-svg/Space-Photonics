📡 Signal Flow

1. Laser Source (1550 nm CW) → Generates continuous-wave optical carrier

2. EO-Kerr Comb → Splits into 64 wavelength channels via Si₃N₄ microresonator

3. Nonlinear XPM → Cross-phase modulation in PCF replaces single-photon detection

4. MZI Mesh → 4×4 photonic matrix multiplication (MAC operations in optical domain)

5. MRR Weight Bank → High-Q resonators apply tunable weights for neural network inference

6. OPA Output → Multi-beam steering to track multiple hypersonic vehicles

7. E-CoPilot → Kalman filtering, error correction, tracking control loop
