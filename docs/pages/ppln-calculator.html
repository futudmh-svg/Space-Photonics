Physics Equations

Quasi-Phase Matching (QPM):
Λ = 2π / |k_p + k_s - k_i| = 2π / |Δk|
where k = 2πn(λ)/λ
Effective Nonlinearity (cascaded χ⁽²⁾):
n₂,eff = (2ω_sω_i d_eff²) / (n_s n_i n_p c² ε₀) × (1/Δk)
For LN: d_eff ≈ 16 pm/V, giving n₂,eff ~ 6×10⁻¹² cm²/W
Normalized Conversion Efficiency:
η_norm = (P_i / P_s) / P_p = (8π² d_eff²) / (ε₀ c n³ λ²) × (L/Λ)² × sinc²(ΔkL/2)
Temperature Tuning:
dΛ/dT = Λ × (α_LN + (1/n)(dn/dT))
α_LN ≈ 15×10⁻⁶ /K, dn/dT ≈ 3.5×10⁻⁵ /K
→ dΛ/dT ≈ 0.14 nm/K for Λ = 6.4 μm
